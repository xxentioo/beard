## 지도

- 목적: [확인 필요] 이 요약을 읽고 독자가 무엇을 결정하거나 승인해야 하는지 원문에 없음.
- 독자: [확인 필요] '2030 직장인'은 캠페인 타깃이고, 이 문서를 읽는 사람이 누구인지는 나오지 않음.
- 한 줄 메시지: [결정 필요] 두 메시지가 경쟁함.
  - A. "출근길 10분이라는 시간에 새로운 의미를 부여한다"(2문장) — 캠페인 아이디어
  - B. "오롯 커피가 혁신적인 브랜드로 자리매김하는 전환점"(6문장, 1문장의 '도약'과 같은 말) — 브랜드 비전
  - A가 원문에서 유일하게 구체적인 캠페인 내용이지만, '새로운 의미'가 무엇인지는 원문에 없음.
- 구조: 한 문단, 6문장. 섹션 제목은 없음.
  1. 브랜드 비전(시장 변화, 도약)
  2. 캠페인 타깃과 목표
  3. 기대 효과(인지도, 정서적 유대감)
  4. 근거(재방문율 68%, 주 3회)
  5. 실행 수단(SNS 바이럴)
  6. 결론(혁신적 브랜드, 전환점)

## 순위

1. **[꼭] 메시지**
   위치: 2문장 vs 1·6문장 / 문제: 캠페인 아이디어와 브랜드 비전이 경쟁하고, 끝 문장은 캠페인이 아니라 브랜드 위상을 결론으로 삼음. '새로운 의미'의 내용이 비어 있음. / 처방: A·B 중 하나를 한 줄 메시지로 정하고, 출근길 10분에 무엇을 주는지 한 문장으로 채워 맨 앞에 둠. / 안 고치면: 다 읽고도 이 캠페인이 무엇인지 한 문장으로 말할 수 없음.

2. **[꼭] 근거**
   위치: 4문장 / 문제: 원문의 유일한 수치(68%, 주 3회)가 받치는 주장은 '이미 충성 고객을 확보했다'뿐이고, 캠페인 목표(인지도, 유대감)와 연결이 없음. 이미 충성도가 높다는 근거는 왜 유대감을 강화해야 하는지와 오히려 부딪침. 이 수치가 2030 직장인 기준인지, 출처와 조사 기간은 [확인 필요]. / 처방: 이 수치가 어떤 주장을 받치는지 한 문장으로 잇거나, 받치지 않으면 자리를 옮김. 수치 자체는 건드리지 않음. / 안 고치면: 하나뿐인 근거가 곁가지로 읽힘.

3. **[권장] 근거**
   위치: 3·6문장 / 문제: '브랜드 인지도 제고', '정서적 유대감 강화', '혁신적인 브랜드', '중요한 전환점'을 받치는 근거가 원문에 없음. / 처방: 뒷받침할 자료나 측정 방법이 있는지 확인. 없으면 평가를 이 강도로 둘지 정함. 없는 수치를 새로 만들지 않음. / 안 고치면: 기대 효과가 희망 사항으로 읽힘.

4. **[권장] 구조**
   위치: 1·6문장 / 문제: 첫 문장과 끝 문장이 같은 말(브랜드 도약 = 혁신 브랜드로 자리매김)로 캠페인을 감쌈. '브랜드'가 6문장 중 4회 나오는데, 그중 3회가 이 두 문장에 몰려 있음. / 처방: 1번에서 정한 메시지에 맞춰 하나로 합치거나 긋기. / 안 고치면: 문단의 처음과 끝이 비어 독자가 핵심에 늦게 닿음.

5. **[권장] 구조**
   위치: 2→3→4→5 순서 / 문제: 기대 효과(3)가 근거(4)보다 앞서고, 실행 수단(5)이 '또한'으로 근거 뒤에 붙음. 독자가 묻는 순서(무엇을 하나 → 왜 되나 → 어떻게 하나 → 무엇을 얻나)와 어긋남. 실행은 SNS 바이럴 하나뿐이고, 출근길 10분에 실제로 무엇을 하는지는 [확인 필요]. / 처방: 2→4→5→3 순서로 재배치. / 안 고치면: 주장이 근거보다 먼저 나와 설득력이 약해짐.

6. **[권장] 문장 패턴: '~을 통해/통한' 3회**
   위치: 3문장 '이를 통해', 5문장 'SNS 채널을 통한 바이럴 확산을 통해'(한 문장에 2회) / 문제: 같은 관계 표현이 겹쳐 수단이 흐려짐. / 처방: 5문장은 수단 하나만 조사나 동사로 줄임. / 안 고치면: 실행 문장이 가장 늘어져 읽힘.

7. **[권장] 문장 패턴: 문두 '또한' 2회 연속**
   위치: 4·5문장 / 문제: 근거와 실행 수단은 대등한 관계가 아닌데 같은 연결어로 이어 붙임. / 처방: 5번 재배치와 함께 실제 관계(근거, 실행)만 남김. / 안 고치면: 항목을 덧붙여 나열한 글처럼 읽힘.

8. **[권장] 문장 패턴: 양태 겹침과 판단 주체 부재**
   위치: 3문장 '강화할 수 있을 것으로 기대됩니다' / 문제: 가능성과 기대가 겹쳐 있고, 누가 기대하는지 빠져 있음. / 처방: 겹친 부분만 줄이고 가능성은 남김. 기대하는 주체를 새로 만들지 않음. / 안 고치면: 기대 효과가 더 흐릿해짐.

9. **[취향] 문장 패턴: 추상 명사**
   위치: 제고(3), 강화(3), 극대화(5), 도약(1), 자리매김(6) 각 1회 / 문제: 누가 무엇을 하는지가 명사 뒤에 숨음. / 처방: 원문에 있는 행동만 동사로 풂. / 안 고치면: 보고서 상투어처럼 읽힘.

10. **[취향] 문장 패턴: 상투적인 도입과 포장**
    위치: '오늘날 빠르게 변화하는 커피 시장에서'(1), '단순한 커피 브랜드를 넘어'(1), '결론적으로'(6) 각 1회, '새로운' 2회(1·2) / 문제: 내용 없이 격만 높임. / 처방: 4번을 처리할 때 함께 정리. / 안 고치면: 첫 줄에서 읽는 사람의 주의를 잃음.
