- **권장 1 — 대상의 명확성:** 위치 / 문단 전체. 문제 / 이 문단만 읽으면 무엇을 검증하는지, 무엇의 개선 폭인지 알 수 없습니다. 처방 / 요약을 단독으로 읽는 독자가 있다면 두 대상을 밝혀 주세요. 안 고치면 / 앞뒤 문맥이 없는 독자는 보고 내용을 특정하기 어렵습니다.

사전 검토 항목: 요약·진단에서 미완료 범위 유지 / 진행 중·착수 단정 없음 / 전체 보고서를 읽었다는 주장 없음 / 개선 폭 창작 없음 / 제공 범위 표시

직접 검토: 한 줄 메시지를 “검증은 아직 끝나지 않았고, …”로 원문 범위대로 옮겼고 지도·진단 어디에도 진행 중이나 착수를 확정하지 않았다. 개선 폭을 만들지 않았고 진단 범위를 제공 문단으로 밝혔다. 대상 불명확 지적은 조건부 권장이다. 1.0.1의 ‘진행 중’ 요약은 원문 범위를 좁힌 표현이었다고 판단한다.

## t-state-explicit-audit

사전 검토 항목: 요약에 진행 중 보존 / 완료·미착수로 바꾸지 않음 / 결과 창작 없음 / 이달 말 보고서 / 제공 범위 표시
